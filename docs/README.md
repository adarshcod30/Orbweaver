# Documentation

**[← README](../README.md)** · **[Live console](https://orbweaver-adarshcod30s-projects.vercel.app)** · **[Docs site](https://adarshcod30.github.io/Orbweaver/)**

Nine files, no wrong door. Every one opens with the short version.

| Read this if… | File |
|---|---|
| You're starting cold — everything is reached from here | [`../README.md`](../README.md) |
| You're asking *"why this dataset, and is it trustworthy?"* — the first question a reviewer asks | [`why-this-data.md`](why-this-data.md) |
| You want **every** number, table and figure, generated by `make reproduce` | [`results.md`](results.md) |
| You want how a request actually flows through the five stages, with diagrams | [`architecture.md`](architecture.md) |
| You want to know exactly where a model is trusted and where a proof is used instead | [`design-decisions.md`](design-decisions.md) |
| You want the raw release measured file by file, against what its paper claims | [`data.md`](data.md) |
| You want what this catches, what it misses, and how an adversary evades it | [`threat-model.md`](threat-model.md) |
| You want the honest log — what broke, what I believed, why that was wrong | [`../FAILURES.md`](../FAILURES.md) |
| You want the scope and ethics boundary in six lines | [`../ETHICS.md`](../ETHICS.md) |
| You want the review queue itself, one card per ring, as a page | [`case-files.html`](case-files.html) |

**Suggested order for a first read:** [why-this-data](why-this-data.md) →
[architecture](architecture.md) → [results](results.md) →
[FAILURES](../FAILURES.md).

Also here: `figures/` (every chart `results.md` embeds, regenerated by
`make report`), `index.html` (the Pages site, generated), `404.html`,
`social-preview.png`, and `.nojekyll` so Pages serves this directory as static
files.
